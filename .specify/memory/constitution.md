# Project Constitution

Version: `1`

## Governance

Human-facing guidance describes intent and implementation shape. The Workflow
V2 StageController journal is the only lifecycle authority.

## Authority principles

- The approved Project Brief and workflow checkpoint provide the machine intent identity.
- Markdown spec, plan, tasks, CLOSEOUT, and HANDOFF files are derived guidance; editing them cannot advance or rewrite the journal.
- Observations, assessments, decisions, receipts, and integration state remain immutable and canonical in the V2 journal.

## Project-wide constraints

Preserve readable history, reject scope expansion, and keep Engine, Project,
and Machine-local Runtime ownership explicit. No destructive migration occurs
without a future Human destructive gate.

## Change rules

Every guidance change is bound to exact artifact digests and a bounded Stage
contract. Derived projections are regenerated from canonical state.
